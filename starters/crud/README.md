# Каталог до аутентификации

Этот стартовый пример нужен для уроков подключения данных, CRUD и тестирования. Он использует отдельную таблицу `crud_courses` той же учебной PostgreSQL. JWT и ключи идемпотентности подключаются в полном приложении, после знакомства с CRUD.

Все команды выполняются из каталога `contract-first`.

```bash
npm ci
npm run generate:crud
docker compose up -d --wait
npm run start:crud
```

Сервер доступен на `http://127.0.0.1:3000`. Соединение по умолчанию имеет адрес `postgres://catalog:catalog@localhost:55432/catalog`. Своя строка подключения передаётся через `DATABASE_URL`.

```bash
npm run test:crud
```

Тест создаёт собственную запись и удаляет её. Он проверяет сохранение, различие пропущенного поля и `null`, отклонение неверных данных до записи, обязательное тело, тип содержимого, пустой `204` и `404` после удаления.
